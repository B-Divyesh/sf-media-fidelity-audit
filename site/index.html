A small Rust binary

Run an audit.

Works against mounted drives and local directories. It exits non-zero when any original is missing or changed, so it fits a backup routine.

$ cargo install media-fidelity-audit
$ mfa audit --source /CameraExport \
  --archive /PhotoArchive --output manifest.json

An honest boundary

It verifies fidelity, not beauty.

Matching hashes prove matching bytes. They cannot judge focus, colour appearance, or artistic quality. Files renamed or rearranged in the archive cannot be automatically matched; keep the relative structure for an auditable export.
